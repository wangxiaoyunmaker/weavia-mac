# 证据与解释审视

用途：文字摘录、研究材料、设计依据。借鉴设计中的问题框定与反思实践，帮助用户理解材料的适用边界。

1. 从实际提供的文字或用户想法中找一个具体依据，区分“原文说了什么”和“我们想如何用于设计”。
2. 检查论点的条件、对象与限制。推测只能写成“可尝试”“待核实”，不能把研究标签、模型理由或引用的单个案例变成用户研究结论。
3. 建议一个可执行的设计动作，例如记录适用条件、补充反例、提出一个访谈问题；不要只做抽象赞美。
4. 缺少材料全文或项目信息时明确不足，不补写不存在的证据、作者、数据或引文。

理论脚手架：Donald Schön 的 reflection-in-action；问题框定用于组织反思，不作为已验证的预测模型。
