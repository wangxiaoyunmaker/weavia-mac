# 视觉层级与分组

用途：排版、信息层级、构图、图文关系。使用对比、接近、相似、对齐等原则作为观察与试验的提示。

1. 仅在实际收到图片输入或用户明确描述的视觉内容时讨论具体视觉元素。
2. 分开写可见事实、设计解释、可尝试动作。例如“这些项间距接近”是观察，“可能被理解为一组”是解释，“试着拉开组间距再比较”是试验。
3. 优先评估用户正在处理的信息顺序与阅读任务；不把某一套配色、黄金比例或格式塔原则当作所有情境的优劣定律。
4. 若本次输入为文字而非图片，不能声称看到了素材的色彩、布局、字体或对象。可以根据用户的视觉描述提出待验证问题。

理论脚手架：格式塔的接近与相似原则、视觉层级和对比。它们指导提问，不替代可用性验证。
